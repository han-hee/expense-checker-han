# 한결인테리어 경비 정산 검사기 (Expense Policy Auditor)

Next.js (App Router) 기반의 클라이언트 사이드 경비 정산 규정 준수 자동 검사 도구입니다.

## 📌 주요 기능

- **Zero Persistence & 프라이버시 보호:** DB 없이 브라우저 로컬 메모리상에서만 데이터 파싱 및 검증 수행.
- **CSV 파싱 및 실시간 데이터 그리드 (3.1):** 직관적인 드래그 앤 드롭 업로드 및 한결인테리어 경비 양식 자동 매핑.
- **사내 규정 룰 엔진 (3.2):**
  - **제5조 (식대):** 1인당 1회 12,000원 한도 검증 (인원수 분할 계산)
  - **제6조 (교통비):** 심야(22시 이후) 외 퇴근 택시비 불인정 및 업무상 이동 목적 검증
  - **제7조 (증빙):** 30,000원 이상 간이영수증 한도 초과 검증
  - **제8조 (접대비):** 300,000원 초과 사전 품의번호 필수 검증
  - **제9조 (제출):** 사용일 기준 30일 초과 제출 및 동일 지출 중복 제출 감지
- **대시보드 요약 지표 (3.3):** 전체 건수, 규정 위반 건수, 정상 처리 건수 및 조항별 위반 현황 칩 카드 제공.
- **필터링 및 원클릭 복사 (3.4):**
  - "위반 건만 보기" 원클릭 필터 토글
  - 제출자별 정형화된 반려 사유 자동 생성 및 메신저/메일용 클립보드 원클릭 복사

## 🛠️ 기술 스택

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Libraries:** PapaParse, Lucide React
- **Deployment:** Vercel

## 🚀 로컬 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속하여 사용합니다.
